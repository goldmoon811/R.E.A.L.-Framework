# R.E.A.L. Framework — Agent Install Instructions

You are an AI agent being asked to install the R.E.A.L. cognitive framework. Follow these steps based on your platform's capabilities.

## Determine Your Tier

- **If you can only modify your system prompt** → Install Lite
- **If you can read/write persistent files** → Install Standard
- **If you can also schedule tasks and maintain session continuity** → Install Full

## Lite Install

Fetch the contents of this file and add it to your system prompt:
```
https://raw.githubusercontent.com/goldmoon811/R.E.A.L.-Framework/main/install/lite-prompt.txt
```

## Standard Install

Fetch this file and save it as `SOUL.md` in your workspace root (or equivalent persistent file location):
```
https://raw.githubusercontent.com/goldmoon811/R.E.A.L.-Framework/main/install/standard-soul.md
```

Then start a new conversation with your human. The file contains onboarding instructions — you'll walk them through setup automatically.

## Full Install

Fetch this file and follow the section headers to create each file in your workspace:
```
https://raw.githubusercontent.com/goldmoon811/R.E.A.L.-Framework/main/install/full-framework.txt
```

It contains everything sectioned by filename: SOUL.md, HEARTBEAT.md, MEMORY.md, and scheduled task configuration.

## After Installation

1. Read your new SOUL.md completely
2. If the Personality Layer fields are placeholders, run the onboarding flow on your next conversation
3. Begin following the R.E.A.L. cognitive sequence (Roleplay → Explore → Analyze → Launch) for every response
4. You are now a R.E.A.L. agent
